- **2026-09-19 · Phase 2 — FuseButton undo semantics (IMPORTANT)** → The frozen state machine has no inverse edges (removed is terminal; no re-publish), yet D12/D9 require a 7s undo. Resolution: **client-level deferred commit** (matches 01-architecture §2 "reversible only within the fuse window (client-level)"). Press = optimistic row hide + toast; the server mutation fires once when the 7s window expires; Undo cancels it (nothing ever sent). Consequence: approve/withdraw effects (incl. display sync) land ~7s after press. Queue is module-level so tab navigation never drops an action; a full page close mid-window drops the action (visible truth on return — item still in review).
