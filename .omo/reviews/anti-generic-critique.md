# Anti-generic self-critique (04 §Definition of done #3)

Per 02-design-system §7's audit framework. Screenshots in `demo/`.

## Display app

The one-signature-moment discipline held: the hero→content clone-flight
transition is the only orchestrated set piece; everything else is feedback.
Structure genuinely comes from the five-step green→blue tonal ramp — section
rules, TOC ticks, chips, keyword tints and showcase underlines all read
"category = color" without a label. Sentence case throughout, no tracked
eyebrows, no `·` meta joins, no `→` suffixes, no ALL-CAPS labels. The showcase
ladder is flat 2D (D20) rather than a 3D cylinder, and the empty states are
prose, not apology boxes. Cards carry no "Learn more" — the whole card is the
button. Where it still leans template: the hero split is a conventional 7/5
editorial layout, and Public Sans is a safe government-grade body face —
deliberate for a university trust context, but the typographic personality
lives almost entirely in Bricolage's variable axes (which the VariableProximity
hover earns). Verdict: distinctive within the "quiet institutional portal"
register, and honest about not being an Awwwards experiment.

## Admin app

The quiet sibling kept its promise: same tokens, same ramp, no decorative
motion — the only animation is the FuseButton undo affordance, which is
functional (7s fuse = 7s server-commit window), not ornament. Tables avoid
the SaaS-default look (no zebra, no vertical lines, hairline rows + 56px
rhythm, category chips from the ramp). Inline editing with three affordances
(right-click, double-click, hidden keyboard button) is an unusual,
power-user-respecting pattern. The "Hi, admin :)" greeting carries the only
personality, exactly per brief. Weak spots: the batch bar and toast system
are conventional patterns (they're invisible until used, which is the right
kind of conventional), and the login card is a standard centered card — fine
for an unlinked internal tool. Verdict: disciplined, ramp-coherent, zero
generic gradients/emoji/marquee sins.

## Cross-check against the recorded anti-generic list

No cream+terracotta, no dark+acid accent, no broadsheet hairline-grid, no
single-radius card kit (20px cards / 999px pills / 12px inputs), no mono meta
labels. Logo sits top-left everywhere. Light theme only (D16). Exactly one
signature moment. Identical verbs across flows ("Approve" everywhere).
